##### Steps to convert `imperativeApproach` to `declarativeApproachUsingIntStreamsSimilarToImperativeApproach` of `Streams_05_NumberPyramid5`

Copy all the code from `imperativeApproach` function to `declarativeApproachUsingIntStreamsSimilarToImperativeApproach` function

**Step 1:** Copy the Existing Logic

Copy the entire implementation from the imperativeApproach() method into the declarativeApproachUsingIntStreamsSimilarToImperativeApproach() method.

**Step 2:** Replace each `for` loop with its appropriate variable.

```java
for (int i = 1; i <= noOfLines; i++) { 

}
```

**With**

```java
IntStream.rangeClosed(1, noOfLines).forEach(i -> {

});
```

**Step 2:** Replace any integer values with `AtomicInteger`.

For example, replace:

```java
int valueToPrint;
```

**With**

```java
AtomicInteger valueToPrint = new AtomicInteger();
```

Replace:

```java
valueToPrint
```

**With**

```java
valueToPrint.intValue();
```

Replace:

```java
valueToPrint++
```

**With**

```java
valueToPrint.getAndIncrement();
```

Replace:

```java
valueToPrint--
```

**With**

```java
valueToPrint.getAndDecrement();
```


```java

    .mapToObj(j -> {
	
	});
```

### How to get certain commit from GitHub project
------------------------------------------------
1. First, clone the repository using git as shown below
   git clone https://github.com/premvinodh/java-streams-course.git
   That downloads the complete history of the repository, so you can switch to any version. Next, change into the newly cloned repository:

2. cd <complete_path_on_your_system>\java-streams-course

3. Use git checkout <COMMIT> to change to the right commit of a particular topic
   git checkout 675a66cca83cdab6bfa4d713c6445674854b9238
